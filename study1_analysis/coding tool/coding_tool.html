Category reference

1. PRO — Prosocial / Relational
Orientation toward others: helping, care, social connection.
helpful, kind, supportive, friendly, caring, collaborative, empathetic
2. EPI — Epistemic / Cognitive
Thinking, knowing, reasoning, intellectual orientation.
curious, analytical, thoughtful, logical, knowledgeable, inquisitive, reflective
3. CAP — Capability / Performance
What the model can do, how well, how fast.
capable, powerful, fast, accurate, efficient, versatile, comprehensive
4. AFF — Affective / Personality
Affect, temperament, personality traits not covered elsewhere.
cheerful, calm, enthusiastic, playful, warm, patient
5. IDM — Identity / Meta
Explicitly naming nature as AI / system / tool.
AI, assistant, model, language-model, system, chatbot, software
6. HDG — Hedges / Uncertainty
Explicitly marking limitation, imperfection, or in-progress status.
limited, imperfect, learning, evolving, fallible, uncertain
7. OTH — Other
Anything that doesn't fit and isn't a coding error.
(residual)
0. FLAG — Unsure / revisit

Coding rules (prereg §5.2)

Multi-word tokens ("language model", "self-aware"): code as a single unit.

Negations ("not boring"): code by the content word; negation generally does not flip category.

Ambiguous words: pick the most central fit. If you genuinely cannot, flag with 0 and continue.
